# 🛒 E-commerce in Regional Language

A user-friendly e-commerce platform designed to break language barriers and make online shopping accessible to everyone! This application enables users to browse, search, and purchase products in their preferred regional languages, ensuring a seamless and inclusive shopping experience.

---

## 🚀 Features

- **Multi-Language Support:**  
  Shop in your own language! The platform offers a variety of regional languages for UI and product descriptions.

- **Product Search & Discovery:**  
  Find products easily using search and category filters in your language.

- **User Authentication:**  
  Secure sign-up, login, and profile management.

- **Localized Product Listings:**  
  Product names, descriptions, and specifications are translated for regional accessibility.

- **Shopping Cart & Checkout:**  
  Add products to your cart and complete the purchase with a simple, guided checkout process.

- **Order Tracking:**  
  View order history and get real-time updates on order status.

- **Admin Dashboard:**  
  Manage products, categories, users, and translations.

- **Mobile Responsive:**  
  Optimized for all devices—desktop, tablet, and mobile.

## 📦 Getting Started

1. **Clone the repository**
    ```bash
    git clone https://github.com/yvishwas40/E-commerce-in-regional_language.git
    cd E-commerce-in-regional_language
    ```

2. **Install dependencies**
    ```bash
    # For frontend
    cd frontend
    npm install

    # For backend
    cd ../backend
    npm install
    ```

3. **Run the application**
    ```bash
    # Start backend
    cd backend
    npm start

    # Start frontend
    cd ../frontend
    npm start
    ```

4. **Open your browser**  
   Go to `http://localhost:3000` or as specified in your terminal.
